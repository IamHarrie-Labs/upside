# Upside mobile (Expo)

The native iOS/Android app. It shares its contract logic with the web app: `src/lib/upside.ts`, `src/abi.ts` and
`src/deployments.ts` are generated by `node ../scripts/sync-mobile.mjs` from `app/src/lib/upside.ts`,
`app/src/abi.ts` and `contracts/deployments/`. Edit the web app's copy, then re-run the script.

Expo SDK 57. Passkeys use Mera through `react-native-passkey`, a native module, so the app runs as a development
or release build, not in Expo Go. One passkey gives the same Monad account in the app and on the website.

## Try it in the browser (no phone needed)

```bash
npm install
npx expo start --web --port 8081
```

With the local chain running (see the root README), the sign-in screen offers the three demo accounts.

## Build an installable Android app (APK)

You need a free Expo account. Nothing below needs Android Studio.

```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview      # testnet; edit EXPO_PUBLIC_* in eas.json first
```

EAS prints a link to the APK when the build finishes. Install it on any Android 9+ phone.

## Make passkeys work on the phone (one-time setup)

A passkey belongs to a domain. Host the web app on that domain, then link the app to it:

1. Pick the domain and set it as `EXPO_PUBLIC_RP_ID` and `EXPO_PUBLIC_WEB_URL` in `eas.json`
   (for example `upside-demo.vercel.app` and `https://upside-demo.vercel.app`).
2. **Android:** run `eas credentials -p android`, copy the SHA-256 fingerprint of the signing key, and paste it into
   `app/public/.well-known/assetlinks.json`.
3. **iOS:** put your Apple Team ID into `app/public/.well-known/apple-app-site-association`.
4. Redeploy the web app so both files are served from `https://<domain>/.well-known/`, then rebuild the app.

Until this is done, the app still runs: browsing, shared links and (on a local chain) demo accounts all work.
Only passkey sign-in needs the domain link.

## Deep links

- `upside://call/3` and `upside://caller/0x…` open a call or a caller profile.
- Share buttons send `https://<domain>/#/call/3` links, which open the web app for anyone without the app.
