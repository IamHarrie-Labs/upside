# Video design reference

Reference: user-supplied Agent CrewArea.mp4 (6.8 seconds, 1464 × 1080).

The web landing reproduces the cream surface, ink typography, rust italic eyebrow, rounded black actions, cloud framing, illustrated portrait strip and aircraft artwork. The original lower-half animation is bundled locally; the original brand and headline are excluded from the crop. Portraits are decorative and are not represented as real Upside users.

Upside account creation, browsing, routes and trading logic remain connected. The app workspace and Expo theme use the same palette. Expo onboarding uses a static poster; native video playback is not implemented.

Checked: production web build, web lint (existing set-state-in-effect warning), mobile TypeScript, desktop/mobile screenshots, account/back/browse navigation, and no horizontal overflow at 390px. Trading transactions and phone passkey login were not rerun for this visual change.
